가입

SmartProxy 가입 · 프록시 생성

프록시가 있어야 계정 생성·신고·트래픽이 돌아갑니다. 아래 초대 링크로 가입한 뒤 한국(KR) 프록시를 만들고, 나온 값을 신고기에 넣습니다.

① 가입

아래 버튼으로 가입하세요. (초대 코드가 자동 적용됩니다)

SmartProxy 가입하기 invite · UH9MV9

참고가입 후 Residential Proxy(주거용, GB당 요금) 상품을 사용합니다. 트래픽(GB)을 조금 충전해두면 바로 쓸 수 있습니다.

② 개요 화면 — App Key 위치

로그인하면 개요 화면 오른쪽에 App Key가 있습니다. 이 값이 신고기 상단의 사용량 표시(app_key)에 쓰입니다.

app_key같은 값을 [프록시 설정 › 인증 방식 › API 추출]의 API 링크 …?app_key=… 에서도 확인할 수 있습니다. 둘 중 편한 곳에서 복사하세요.

③ 프록시 만들기 (아이디&비번 · 한국)

프록시 › Residential Proxy › [프록시 설정] 탭에서 아래 순서로 진행합니다.

  1. 인증 방식 아이디&비번 인증 API 추출 — 아이디&비번 인증 선택
  2. 프록시 생성기에서 국가 = South Korea 선택 (도시·주·ASN은 랜덤 그대로 OK)
  3. 오른쪽 [프록시 생성] 클릭 → 접속 값이 만들어집니다

생성되면 프록시 목록 생성 박스에 접속 값이 나옵니다.

④ 신고기 어디에 넣나 (실제 화면)

신고기 [아이피 변경] 탭입니다. 아래 번호가 SmartProxy 값과 연결됩니다.

1서버←Proxy Server (proxy.smartproxy.net)
2포트←Port (3120)
3아이디←username (…_area-KR 까지 전체)
4비밀번호←password
5app_key←App Key (대시보드 개요 또는 [API 추출])
꼭 확인username 끝에 _area-KR 이 붙어 있어야 한국 IP로 나갑니다. 안 붙으면 해외로 나가 네이버가 즉시 차단합니다. 넣은 뒤 신고기에서 [연결 테스트] → 한국 IP 확인 → [저장].
헷갈리지 않기프록시 접속용 username/password(아이디·비번)와 사용량 조회용 App Key는 서로 다른 값입니다.
01

프록시 — 아이피 변경

계정 생성·생존확인·신고·트래픽이 모두 이 프록시로 나갑니다. 저장하지 않으면 집 IP로 나가 네이버가 바로 막습니다. 반드시 한국(KR) 프록시로 설정하세요.

입력칸넣는 값
서버proxy.smartproxy.net
포트3120
아이디하위계정 뒤에 _area-KR 을 꼭 붙입니다 — 예 smart-xxxxxxxx_area-KR 한국 필수
비밀번호SmartProxy 하위계정(sub-user) 비밀번호
  1. 연결 테스트 — 누르면 프록시로 실제 나가는 IP가 표시됩니다. 한국 IP가 나오면 정상.
  2. 저장 — 저장해야 이후 모든 작업이 이 프록시로 나갑니다. (필수)
주의_area-KR 을 빼면 해외 IP로 나가 네이버가 즉시 차단합니다. SmartProxy 대시보드에서 국가를 South Korea로 골라 만든 하위계정 값을 넣으세요.
02

트래픽 사용량 — app_key

상단 헤더의 🌐 프록시 사용 N GB는 최근 30일 소비한 트래픽입니다. 표시하려면 SmartProxy의 app_key가 필요합니다.

app_key 얻는 법

  1. SmartProxy 대시보드 [프록시 설정] 탭으로 이동
  2. 인증 방식에서 [API 추출] 선택
  3. 국가를 South Korea 로 선택
  4. 오른쪽 API 링크에 생기는 주소에서 …get?app_key=XXXXXXXX&pt=9… 의 app_key 값만 복사
  5. 앱 [아이피 변경 › 트래픽 사용량 조회] 칸에 붙여넣고 [사용량 확인]
복사 범위app_key= 뒤부터 다음 & 기호 전까지가 app_key 값입니다. &pt=·&cc= 등 뒤 파라미터는 넣지 마세요.
헷갈리지 않기app_key ≠ 프록시 비밀번호. 프록시 접속용 아이디/비번(smart-…_area-KR)과 사용량 조회용 app_key는 서로 다릅니다. app_key는 계정 공용 키라 아이디·비번 없이 그것만 넣으면 됩니다.

호출은 생성·신고·트래픽 실행 때 자동 1회(90초 이내 재호출은 생략) + 시작 시 1회 + 수동 버튼. 과호출로 차단되지 않게 설계돼 있습니다.

03

계정 생성 · 생존 확인

신고에 쓸 네이버 계정을 서버에서 만들고 AntiDetect 프로필에 로그인 상태로 연결합니다.

  1. 생성 개수 입력 — 개수만큼 포인트가 차감됩니다. (예상 차감액이 옆에 표시)
  2. 계정 생성 — 포인트가 없으면 생성되지 않으니 충전을 먼저 하세요. 진행 중 경과 시간이 실시간으로 올라갑니다(계정 하나에 수 분 소요).
  3. 생존 확인 — 만든 계정이 실제 로그인되는지 확인합니다. 신고에는 생존 확인을 통과한 계정만 쓰입니다.

💎 포인트 충전 (생성 전 준비)

계정 생성은 개당 1,000P가 듭니다. 포인트가 없으면 먼저 충전을 요청하세요. 운영자(개발자)가 입금을 확인하고 승인해야 포인트가 적립됩니다.

  1. 사이드바 포인트 아래 [눌러서 충전 요청] 클릭
  2. 충전 금액 입력(예: 50,000) 또는 빠른 버튼(10천P·50천P·10만P) → [확인]
  3. 운영자(개발자)가 입금 확인 후 승인 — 승인 전까지는 포인트가 오르지 않습니다
  4. 승인되면 포인트 적립 → 계정 생성 시 개당 1,000P씩 차감

🩺 생존 확인 (live check)

만든 계정이 실제로 로그인되는지 확인합니다. 신고에는 "정상"으로 확인된 계정만 쓰입니다. [보유 계정]에서 [🩺 생존 확인]을 누르면 정상 / 정지 / 미확인으로 집계됩니다.

팁보유 계정 목록에서 …_live(o) 정상은 로그인 확인됨, (?) 미확인은 아직 생존 확인 전입니다. 정지된 계정은 신고에 쓰이지 않습니다.
04

AntiDetect Browser (로컬)

파워링크 트래픽에 쓸, 내 PC에 설치된 AntiDetect를 연결합니다. API 키를 넣고 연결 확인을 누르면 ✅ 연결됨 · 프로필 N개가 표시됩니다.

API 키 얻는 법 (AntiDetect Browser)

신고기의 API 키 칸에 넣는 값은 AntiDetect Browser 앱에서 발급받습니다. 키가 두 종류라 헷갈리지 마세요.

  1. 앱 로그인 키 — AntiDetect Browser 마이페이지에 있는 xxxx-xxxx-xxxx-xxxx-xxxx 형식 키. 이걸로 AntiDetect Browser 앱에 로그인합니다.
  2. 로그인 후 [마이페이지] → API 키 / 포인트 로 이동
  3. API 키(sk_…)를 복사 — 없거나 바꾸려면 [재발급] (기존 키는 즉시 무효화)
  4. 그 sk_… 키를 신고기 [AntiDetect Browser] API 키 칸에 붙여넣고 [연결 확인]
두 키 구분앱 로그인 키(xxxx-xxxx-…)는 AntiDetect 앱 로그인용, API 키(sk_…)는 신고기에 넣는 값입니다. API 는 호출당 포인트(₩5)가 차감되니 마이페이지에서 포인트 잔액도 확인하세요.
별개입니다여기 키는 내 PC의 로컬 AntiDetect 키입니다. 신고·계정 생성에 쓰는 서버용 AntiDetect와는 다릅니다. 포트는 화면에 노출되지 않고 내부적으로 관리됩니다.
05

키워드 신고

검색어로 상위 게시물을 찾아 한꺼번에 신고합니다. (블로그 전용, 카페는 비활성)

  1. 키워드 · 최대 수 입력 — 검색 상위 몇 개까지 신고할지 정합니다.
  2. 제외 주소 — 신고에서 뺄 게시물 URL을 하나씩 추가하면 결과에서 자동으로 빠집니다.
  3. 검색으로 결과를 미리 본 뒤 ＋ 스케줄 추가로 키워드를 담습니다 (여러 개 가능).
  4. ▶ 스케줄 시작 — 담긴 키워드들을 순서대로 검색해 신고합니다. 배분을 랜덤으로 하면 사유가 무작위로 섞입니다.
06

특정 게시물

URL을 직접 지정해 신고합니다.

  1. 게시물 URL을 하나씩 [+ 추가]해서 목록을 만듭니다.
  2. 행마다 사유를 정하거나, 🎲 사유 랜덤 배치로 무작위로 섞습니다.
  3. 시작하면 목록의 게시물을 신고합니다.
07

신고 공통 설정

키워드·특정 게시물·게시물 삭제 모든 신고 방식에 함께 적용됩니다. ([아이피 변경] 하단)

IP 로테이션1건 신고할 때마다 실제 IP를 바꿉니다.
신고 간격신고 사이 간격을 랜덤 범위(예 10~20초)로 둡니다.
중복 방지같은 아이디가 같은 게시글을 두 번 신고하지 않게 막습니다.
08

계정 신고 리스트

내가 만든 계정들이 어떤 게시글을 신고했는지 서버에서 조회합니다. [🔄 새로고침]으로 최신 기록을 불러옵니다.

보안본인(entid) 계정의 기록만 보입니다. 남의 계정 기록은 조회되지 않습니다.
09

파워링크 트래픽

경쟁 광고의 예산을 소진시키는 기능입니다. 검색 → 대상 담기 → 클릭 방문.

  1. 키워드 검색 — 상단 파워링크(광고) 목록을 불러옵니다. 제목↔URL이 정확히 매칭됩니다.
  2. ＋ 추가로 원하는 광고를 트래픽 대상에 담습니다. 담긴 항목은 버튼이 ✓ 담김(회색)으로 바뀝니다. ＋ 전체 추가도 가능.
  3. 방문 방식 선택 — 대상마다 N회(각 광고 N번) 또는 전체 N회 순환(대상들을 돌며 총 N번). 총 횟수가 옆에 표시됩니다.
  4. 체류·간격(초)을 랜덤 범위로 두고 ▶ 트래픽 시작.
동작 원리트래픽은 네이버 검색결과의 파워링크 링크를 실제로 클릭합니다. 이 클릭이 네이버 클릭추적(adcr.naver.com)을 타야 광고주에게 과금됩니다. URL 직접 방문은 광고비가 빠지지 않으므로 하지 않습니다 — 내가 담은 광고를 못 찾으면 엉뚱한 업체를 누르지 않고 건너뜁니다.
로그로 확인매 방문마다 SmartProxy 우회 IP, 클릭 → 제목 [도메인], 도착: URL이 찍혀 어떤 IP로 어떤 업체를 눌렀는지 확인할 수 있습니다. 결과는 트래픽 전용 CSV로 저장됩니다.
10

결과 · 로그

📥 결과물 받아보기탭에 따라 다릅니다. 트래픽 탭이면 트래픽 결과표, 신고 탭이면 신고 결과표(CSV)를 저장합니다.
하단 통계트래픽 탭에선 트래픽 완료·성공률, 신고 탭에선 신고 완료·성공률로 자동 전환됩니다.
💾 로그 저장 / 📮 로그 보내기처리 로그를 파일로 저장하거나 운영자에게 전송합니다.

트래픽 CSV 컬럼: 순번 · 시각 · 키워드 · 대상 제목 · 대상 URL · 클릭 도메인 · 도착 URL · 우회 IP · 결과.

주의 & 자주 묻는 것

프로그램을 껐다 켜면 최신인가요?

네. 켤 때마다 서버에서 최신 버전을 받아 실행합니다. 새 버전이 있으면 시작할 때 업데이트 안내 팝업이 뜹니다.

트래픽에서 "못 찾아 건너뜀"이 자주 떠요

네이버 파워링크가 노출되지 않았거나 담은 광고가 그 검색에 안 나온 경우입니다. 엉뚱한 업체를 클릭하지 않기 위한 안전장치입니다. 계속되면 키워드를 바꿔 다시 검색하세요.

AntiDetect가 "연결 안됨"이에요

내 PC에서 AntiDetect Browser 앱을 먼저 실행한 뒤, 신고기 [AntiDetect Browser] 탭에서 [연결 확인]을 눌러 상태를 확인하세요.
